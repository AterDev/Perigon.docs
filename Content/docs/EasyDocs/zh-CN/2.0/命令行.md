# 命令行

安装后的可执行文件是 `ezdoc`。不带参数或使用 `--help` 可以查看当前命令帮助：

```powershell
ezdoc --help
```

## 命令

### `init [path]`

在 `path` 目录初始化站点工作区。省略 `path` 时使用当前目录。

```powershell
ezdoc init .
ezdoc init .\MyDocs
```

### `build [configPath]`

根据 `webinfo.json` 生成静态站点：

```powershell
ezdoc build .\webinfo.json
```

## 全局选项

- `-h`、`--help`：显示应用或当前命令的帮助；
- `-v`、`--version`：显示已安装的包版本。

命令名在所有语言环境下都保持为 `init` 和 `build`。CLI 会根据当前 UI 语言加载对应的本地化资源：中文系统显示中文说明，英文系统显示英文说明。也可以通过环境变量 `DOTNET_CLI_UI_LANGUAGE` 设置为 `zh-CN` 或 `en-US` 覆盖系统检测结果。终端支持 ANSI 颜色时，生成过程会使用不同颜色区分成功、信息、警告和错误。
