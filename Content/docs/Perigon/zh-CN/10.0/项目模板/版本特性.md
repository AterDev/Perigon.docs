# 版本特性

本篇文章主要介绍各版本的主要特性。

## 10.0 / 模板包 1.3.11

- 默认集成`.NET Aspire`。
- `ApiStandard` 使用 `Swashbuckle` 提供 OpenAPI JSON；`MiniApi` 使用 ASP.NET Core OpenAPI，默认文档为 `/openapi/v1.json`。
- 默认使用`.slnx`作为解决方案文件。
- 默认使用`CPM`中央包管理。

### 版本兼容矩阵

| 组件 | 当前版本/要求 | 说明 |
| --- | --- | --- |
| `Perigon.templates` | `1.3.11` | 本页对应的模板包版本 |
| .NET SDK | `10.0.103` 或兼容的 .NET 10 SDK | 两套模板目标框架为 `net10.0` |
| Aspire AppHost SDK | `13.4.6` | 两套模板统一版本 |
| Aspire Hosting 包 | `13.4.6` | 与 AppHost SDK 保持一致 |
| `ApiStandard` | `perigon-webapi` | EF Core、MigrationService、Admin/API、多数据库 |
| `MiniApi` | `perigon-miniapi` | Minimal API、PostgreSQL、NativeAOT、无 MigrationService |

模板包版本和文档版本不是同一个概念：`10.0`表示 .NET/Perigon CLI 主版本线，`1.3.11`表示 `Perigon.templates` 发布版本。升级模板包时，应同步更新本矩阵和两套快速入门。
