# EasyDocs 2.0

EasyDocs 是一个基于 .NET 的命令行工具，可以将 Markdown 内容生成纯静态网站。生成结果只包含 HTML、CSS、JavaScript、JSON 和静态资源，因此可以部署到 GitHub Pages、CDN 或普通的静态文件服务器。

- 文档地址：[https://dusi.dev/docs/EasyDocs.html](https://dusi.dev/docs/EasyDocs.html)
- 源代码仓库：[https://github.com/AterDev/EasyDocs](https://github.com/AterDev/EasyDocs)

## 可以生成的内容

一个 EasyDocs 站点可以包含：

- 首页和关于页面；
- 博客列表、博客分类和 Markdown 博客页面；
- 多版本、多语言技术文档；
- 多语言产品入口页和产品文档；
- 搜索数据、搜索页面、canonical 链接和 sitemap；
- 自定义 CSS、JavaScript、HTML、图片及其他静态文件。

EasyDocs 不会在生成结果中运行 Web 服务器，输出目录本身就是部署产物。

## 版本模型

文档版本 `2.0` 是内容目录和 `DocInfos[].Versions` 中的版本段，与 NuGet 包版本相互独立。一个站点可以同时发布多个文档版本，而 CLI 包仍然可以继续发布补丁版本。
