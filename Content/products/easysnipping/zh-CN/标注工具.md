# 标注工具

![标注工具示例](../assets/sc3_markup.png)

确认截图区域后，工具栏会出现在选区附近。标注内容会叠加到当前截图上，导出或复制时一起处理。

## 可用工具

| 工具 | 用途 |
| --- | --- |
| 矩形、椭圆 | 标出区域或重点内容 |
| 箭头、直线 | 指向目标或分隔内容 |
| 文字 | 添加说明、步骤和标题 |
| 高亮 | 强调原图中的内容 |
| 马赛克 | 遮挡敏感信息 |
| 画笔 | 自由绘制或快速圈画 |

## 常用样式

- 矩形和椭圆支持透明度以及边框/填充模式。
- 箭头支持单箭头或双箭头。
- 直线支持实线或虚线。
- 文字支持调整字号、粗体和斜体。
- 马赛克画笔支持调整笔刷范围。
- 颜色包括红、蓝、绿、黄和白。

这些增强选项只作用于当前截图会话，不会改变后续截图的默认设置。默认工具和快捷键会显示在工具栏提示中。

## 编辑建议

先完成选区，再添加标注。需要重新选择区域时，先保存或复制当前结果；取消截图会话会丢弃尚未导出的内容。使用撤销按钮可以移除最近一次标注。
