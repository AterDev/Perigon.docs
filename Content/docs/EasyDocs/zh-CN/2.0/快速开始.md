# 快速开始

为站点内容创建一个仓库目录，然后执行初始化：

```powershell
mkdir MyDocs
cd MyDocs
ezdoc init .
```

`init` 会创建 `webinfo.json`、`Content` 目录、示例文档目录、博客目录和 `about.md`。路径参数可以省略，省略时使用当前目录。

在 `Content` 下添加 Markdown 文件后生成站点：

```powershell
ezdoc build .\webinfo.json
```

输出目录由 `OutputPath` 控制，默认是 `./WebSite`。可以使用任意静态文件服务器预览：

```powershell
npx http-server .\WebSite
```

## 最小工作流

1. 将 `webinfo.json` 放在仓库根目录。
2. 将博客、文档、产品和自定义资源放到 `Content` 下。
3. 在 `DocInfos` 中声明每个文档、语言和版本。
4. 内容变更后执行 `ezdoc build .\webinfo.json`。
5. 部署完整的输出目录。

只要显式传入配置文件路径，就可以从任意目录运行生成命令。
