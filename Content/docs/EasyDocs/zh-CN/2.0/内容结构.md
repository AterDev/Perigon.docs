# 内容结构

默认内容目录如下：

```text
Content/
├── about.md
├── blogs/
├── custom/
├── docs/
│   └── EasyDocs/
│       ├── en-US/2.0/
│       └── zh-CN/2.0/
└── products/
    └── MyProduct/
        ├── logo.svg
        ├── en-US/
        └── zh-CN/
```

## 博客

`Content/blogs` 下的每个 Markdown 文件都会生成博客页面，子目录会成为博客分类。图片和其他静态文件会复制到对应的输出路径。

## 技术文档

文档路径格式为 `docs/<name>/<language>/<version>/...`，其中名称、语言和版本必须在 `DocInfos` 中声明。例如：

```text
Content/docs/EasyDocs/zh-CN/2.0/快速开始.md
```

会生成：

```text
WebSite/docs/EasyDocs/zh-CN/2.0/快速开始.html
```

可以使用 `.order` 文件控制 Markdown 文件和目录的混排顺序，条目不包含 `.md` 后缀：

```text
介绍
快速开始
高级主题
常见问题
```

相对 Markdown 链接会将 `.md` 转换为 `.html`，绝对 HTTP(S) 链接保持不变。`custom` 下的文件最后复制，可以覆盖内置 CSS、JavaScript、模板或生成页面。
