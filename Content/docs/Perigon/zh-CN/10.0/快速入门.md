# 快速入门

Perigon 提供两套用途不同的模板。请先选择模板，再按对应指南创建、运行和测试项目。

| 模板 | 适用场景 | 技术边界 | 快速入门 |
| --- | --- | --- | --- |
| `ApiStandard` | 标准 Web API、后台服务和模块化业务系统 | EF Core、Aspire 迁移资源、AdminService/ApiService、PostgreSQL 或 SQL Server | [ApiStandard 快速入门](./项目模板/ApiStandard快速入门.md) |
| `MiniApi` | 轻量接口、微服务和资源敏感场景 | Minimal API、PostgreSQL、NativeAOT、无内置 EF 迁移资源 | [MiniApi 快速入门](./项目模板/MiniApi快速入门.md) |

## 公共前提

1. 安装 `.NET 10.0.103` 或兼容的 .NET 10 SDK。
2. 安装与模板 SDK 匹配的 Aspire CLI（当前开发版本为 13.5.0），并准备 Docker 或 Podman。
3. 安装 `Perigon.CLI` 后使用 `dotnet new` 创建模板，或使用 Studio 创建解决方案。

直接使用模板包时，安装与本文档对应的版本：

```powershell
dotnet new install Perigon.templates --version 1.3.12
```

模板版本、Aspire SDK 和 CLI 的对应关系请查看[版本兼容矩阵](./项目模板/版本特性.md)。

## 运行和排障约定

AppHost 使用 Aspire CLI 管理，不要直接把 AppHost 当作普通 Web 项目启动：

```pwsh
aspire start --non-interactive
aspire ps
aspire otel logs
```

停止应用：

```pwsh
aspire stop --non-interactive
```

生产发布前请阅读[生产运维 Runbook](./教程/生产运维Runbook.md)和[发布应用](./教程/发布应用.md)。
