EasySnipping Privacy Policy / 隐私政策

Effective date / 生效日期：August 12, 2026 / 2026 年 8 月 12 日

This privacy policy applies to the EasySnipping Windows application.
本隐私政策适用于 EasySnipping Windows 应用。

Information processed / 我们处理哪些信息

EasySnipping does not require an account and does not provide advertising, social features, or cloud account services inside the app.
EasySnipping 不要求用户创建账号，也不在应用内提供广告、社交功能或云端账户服务。

  • Screen content / 屏幕截图内容：The app captures screen content only when you actively start a capture. / 只有在你主动开始截图时，应用才会捕获屏幕内容。
  • Annotations and OCR text / 标注和 OCR 文本：Processed in local memory by default. Windows OCR is provided by capabilities on the device; availability depends on Windows and installed language packs. / 默认在本机内存中处理。Windows OCR 由设备上的系统能力提供，是否可用取决于 Windows 系统和已安装的语言包。
  • Exported files / 导出文件：When you choose Save, the app writes PNG or JPEG files to the directory you select. / 当你选择保存时，应用会将 PNG 或 JPEG 文件写入你选择的目录。
  • Clipboard content / 剪贴板内容：When you choose to copy a screenshot or OCR result, the content is written to the Windows clipboard. / 当你选择复制截图或 OCR 结果时，内容会写入 Windows 剪贴板。
  • Settings / 设置：The app stores shortcuts, save directory, theme, language, OCR, and other preferences locally. / 应用会在本机保存快捷键、保存目录、主题、语言、OCR 选项和其他偏好设置。

What we do not do / 我们不会做什么

In the current version, EasySnipping does not proactively upload, sell, or share screenshots, OCR text, annotations, or app settings with the application provider. It does not use advertising trackers and does not require a network connection for basic capture, annotation, saving, or copying.
在当前版本中，EasySnipping 不会主动向应用提供方上传、出售或共享屏幕截图、OCR 文本、标注内容或应用设置；不使用广告追踪器，也不要求网络连接来完成基本截图、标注、保存和复制操作。

If you use Windows or another app's sync, backup, sharing, or clipboard-management features, those features are handled by their respective providers under their own privacy policies.
如果你使用 Windows 或其他应用提供的同步、备份、分享或剪贴板管理功能，这些功能将由相应服务提供方按照其自己的隐私政策处理。

Retention and deletion / 数据保留和删除

Exported screenshots, clipboard content, and local settings are controlled by you. You can delete exported files, clear the clipboard, or remove app settings. Uninstalling the app does not automatically delete screenshots you exported; delete those files manually from the save directory if needed.
导出的截图、剪贴板内容和本机设置由你控制。你可以删除导出文件、清理剪贴板或删除应用设置。卸载应用不会自动删除你主动导出的截图；如需删除，请从保存目录中手动删除。

Third-party components / 第三方组件

The app uses Windows and Windows App SDK system components, including Windows OCR capabilities. Those system components may be subject to Microsoft's terms and privacy policy.
应用使用 Windows 和 Windows App SDK 提供的系统组件，包括 Windows OCR 相关能力。这些系统组件可能受 Microsoft 的条款和隐私政策约束。

Contact / 联系方式

Official website / 官方网站：https://dusi.dev

For questions about this policy or EasySnipping's data handling, contact the application provider through the contact method published on the official website.
如需就本隐私政策或 EasySnipping 的数据处理方式联系我们，请通过官方网站提供的联系方式联系应用提供方。

Policy updates / 政策更新

If the app's data handling changes, we will update this policy's effective date and provide the latest version on this page.
如果应用的数据处理方式发生变化，我们会更新本隐私政策的生效日期，并在本页面提供最新版本。
