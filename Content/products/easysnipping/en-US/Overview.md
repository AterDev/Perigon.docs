# EasySnipping

![EasySnipping icon](/products/easysnipping/logo.png)

EasySnipping is a lightweight Windows screenshot and annotation tool for capturing screen content, highlighting important details, and using the result immediately.

## Core capabilities

- Start a capture with the global shortcut, the tray menu, or the tray icon.
- Detect windows and controls automatically, or drag a free-form selection.
- Capture across multiple monitors and the virtual desktop coordinate space.
- Annotate with rectangles, ellipses, arrows, lines, text, highlights, mosaics, and freehand drawing.
- Use Windows OCR to recognize text in the selection and copy the result.
- Save as PNG/JPEG, copy to the clipboard, or keep the result as an always-on-top image pin.
- Configure the Chinese or English interface, theme, save directory, OCR backend, and startup behavior.

Screenshots, annotations, and OCR text are processed locally by default. EasySnipping does not require an account, and exported files are written only when you choose to save them.

## Get started

1. Open EasySnipping and confirm that it is running in the system tray.
2. Press `Ctrl+Shift+S`, or choose the capture command from the tray menu.
3. Select a window, control, or free-form region, then edit the result.
4. Save, copy, or pin the screenshot.
