# 部署与自定义

`OutputPath` 目录就是完整的静态站点。部署时上传其中的全部文件，目标服务器不需要安装 .NET Runtime。

## 部署到子路径

将 `BaseHref` 设置为包含结尾 `/` 的部署前缀：

```json
{
  "BaseHref": "/docs/"
}
```

修改后重新生成。导航链接、脚本、样式、canonical 和 sitemap 都会使用配置的基础路径。

## 自定义静态资源

将文件放到 `Content/custom` 下，可以覆盖内置资源或添加静态文件：

```text
Content/custom/
├── css/app.css
├── css/docs.css
├── js/site.js
└── images/banner.svg
```

自定义文件会在内置内容生成完成后复制。同路径文件会覆盖生成结果。新增 CSS 或 JavaScript 会被复制，但不会自动注入所有内置页面；如果需要全局加载，应覆盖模板或对应的内置资源。

## CI 生成

CI 中可以使用以下步骤：

```powershell
dotnet tool install -g Ater.EasyDocs
ezdoc build ./webinfo.json
```

最后将 `OutputPath` 目录交给静态站点发布动作即可。
