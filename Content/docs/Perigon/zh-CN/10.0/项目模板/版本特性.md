# 版本特性

本篇文章主要介绍各版本的主要特性。

## 10.0 / 模板包 1.3.16

- 默认集成`.NET Aspire`。
- `ApiStandard` 使用 `Swashbuckle` 提供 OpenAPI JSON，并在非生产环境提供 `/swagger` UI；`MiniApi` 使用 ASP.NET Core OpenAPI，默认文档为 `/openapi/v1.json`。
- 默认使用`.slnx`作为解决方案文件。
- 默认使用`CPM`中央包管理。
- `ApiStandard` 默认按多租户运行；初始化时会为 `default.com` 写入默认业务和分析数据库连接串，租户解析不会对缺失或未知租户静默回退。
- `ApiStandard` 与 `MiniApi` 默认提供按迭代组织的 PD/PT 文档、实现进度记录和 AI 交付闭环。
- `MiniApi` 提供 Minimal API 与 Native AOT 专项技能，用于检查 endpoint 静态绑定、JSON、Trim、依赖和发布证据。
- 集成测试数据库配置与 AppHost Testing 环境保持一致，清理前会校验实际测试数据库名。
- ApiStandard 和 MiniApi 使用统一源代码生成器，并自动注册 Minimal API endpoint group；MiniApi 补充 Native AOT JSON metadata。
- 两套模板的 `IUserContext.RoleIds` 从 `role_id` GUID Claims 读取有效、唯一的角色 ID。
- ApiStandard MVC 自动模型验证失败返回 HTTP 400，JSON 包含 `title`、`detail`、`status` 和 `traceId`。
- ApiStandard 局部更新忽略 `Id`、`TenantId` 和 `CreatedTime`，批量插入只枚举输入一次；两套模板修复嵌套 `Between` 查询。
- 移除内置图形验证码 helper 和 ImageSharp 依赖；调用旧 helper 的项目需要迁移。

### 版本兼容矩阵

| 组件 | 当前版本/要求 | 说明 |
| --- | --- | --- |
| `Perigon.templates` | `1.3.16` | 本页对应的模板包版本 |
| .NET SDK | `10.0.103` 或兼容的 .NET 10 SDK | 两套模板目标框架为 `net10.0` |
| Aspire AppHost SDK | `13.5.0` | 当前开发版本，两套模板统一版本 |
| Aspire Hosting 包 | `13.5.0` | 与 AppHost SDK 保持一致；EF Core 和 Kubernetes hosting 包当前为 preview 包 |
| `ApiStandard` | `perigon-webapi` | EF Core、Aspire 迁移资源、Admin/API、多数据库 |
| `MiniApi` | `perigon-miniapi` | Minimal API、PostgreSQL、NativeAOT、无内置 EF 迁移资源 |

模板包版本和文档版本不是同一个概念：`10.0`表示 .NET/Perigon CLI 主版本线，`1.3.16`表示 `Perigon.templates` 发布版本。升级模板包时，应同步更新本矩阵和两套快速入门。
