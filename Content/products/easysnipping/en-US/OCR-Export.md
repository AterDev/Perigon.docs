# OCR, saving, and pinning

![Always-on-top image pin](../assets/sc4_stick_top.png)

After capturing and annotating, choose the action that fits your workflow: OCR, save, copy, or pin.

## Windows OCR

1. Confirm the screenshot region.
2. Click the OCR button on the toolbar, or use the OCR shortcut.
3. Review the recognized text in the OCR panel and copy it when needed.

OCR runs asynchronously on the device. Availability depends on the Windows version, device capabilities, and installed language packs. If no suitable language pack is available, OCR may be unavailable; choose a preferred OCR language in Settings or leave it on automatic selection.

## Save and copy

- Save as PNG or JPEG.
- PNG is suitable for lossless output; JPEG can reduce file size through the quality setting.
- Copy writes the annotated screenshot to the Windows clipboard.
- OCR results can be copied as text separately.

The default save directory is `Pictures\Snipping`; change it in Settings. Screenshot content is written to a local destination only when you explicitly save or copy it.

## Always-on-top image pins

Pin a screenshot as a semi-transparent image above other windows when you need a visual reference, comparison, or temporary note. Pin opacity and the shortcut can be changed in Settings.
