# EasySnipping

![EasySnipping 图标](/products/easysnipping/logo.png)

EasySnipping 是一款轻量的 Windows 截图与标注工具，帮助你快速捕获屏幕内容、标注重点，并立即保存、复制或置顶使用。

## 核心能力

- 使用全局快捷键、托盘菜单或托盘图标开始截图。
- 自动识别窗口和控件，也支持自由拖拽选区。
- 支持多显示器和虚拟屏幕坐标。
- 使用矩形、椭圆、箭头、直线、文字、高亮、马赛克和画笔标注。
- 使用 Windows OCR 识别选区中的文字，并复制识别结果。
- 将结果保存为 PNG/JPEG、复制到剪贴板，或作为置顶贴图保留在其他窗口上方。
- 支持中文和英文界面、主题、保存目录、OCR 后端和开机自启设置。

截图、标注和 OCR 文本默认在本机处理；EasySnipping 不要求账号。导出文件只会在你主动保存时写入选择的目录。

## 开始使用

1. 打开 EasySnipping，确认它已经在系统托盘中运行。
2. 按 `Ctrl+Shift+S`，或从托盘菜单选择立即截图。
3. 选择窗口、控件或自由拖拽区域，然后使用编辑工具处理结果。
4. 保存、复制或置顶截图。
