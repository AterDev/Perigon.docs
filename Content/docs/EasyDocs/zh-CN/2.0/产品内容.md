# 产品内容

产品内容独立于带版本的 `DocInfos`，通过 `ProductInfos` 配置：

```json
{
  "ProductInfos": [
    {
      "Name": "MyProduct",
      "Description": "一个多语言产品指南",
      "Logo": "logo.svg",
      "Languages": ["en-US", "zh-CN"],
      "DefaultLanguage": "zh-CN"
    }
  ]
}
```

对应的内容目录如下：

```text
Content/products/MyProduct/
├── logo.svg
├── privacy-policy.html
├── en-US/
│   ├── .order
│   └── Getting-Started.md
└── zh-CN/
    ├── .order
    └── 快速开始.md
```

`DefaultLanguage` 目录中的第一篇 Markdown 会生成产品入口页：

```text
products/MyProduct.html
```

各语言文档生成到 `products/MyProduct/<language>/...`，并分别生成搜索页和搜索 JSON。产品导航、语言切换、目录树、canonical、编辑链接和 sitemap 与 Docs 链路独立生成。

产品根目录下的非 Markdown 文件会原样复制。例如 `privacy-policy.html` 仍然可以通过 `products/MyProduct/privacy-policy.html` 访问，EasyDocs 不会改写其 HTML 或内部链接。
