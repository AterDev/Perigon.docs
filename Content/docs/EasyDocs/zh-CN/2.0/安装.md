# 安装

EasyDocs 运行在 .NET 10 上，可以从 NuGet 安装全局工具：

```powershell
dotnet tool install -g Ater.EasyDocs
```

升级已有安装：

```powershell
dotnet tool update -g Ater.EasyDocs
```

验证安装结果：

```powershell
ezdoc --version
ezdoc --help
```

命令行帮助会显示当前版本、EasyDocs 文档地址和 GitHub 仓库地址。命令使用稳定的英文名称（`init` 和 `build`），同时支持中文别名（`初始化` 和 `生成`）。说明会根据系统 UI 语言优先显示中文或英文，并同时提供另一种语言。

## 环境要求

- .NET 10 SDK，或能够运行该工具的 .NET 10 Runtime；
- 对源内容目录和生成目录具有写入权限；
- 预览生成结果时使用任意静态文件服务器。

最终部署站点不需要数据库、Web 框架或 .NET Runtime。
