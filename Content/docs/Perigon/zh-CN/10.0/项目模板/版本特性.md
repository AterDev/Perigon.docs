# 版本特性

本篇文章主要介绍各版本的主要特性。

## 10.0 / 模板包 1.3.14

- 默认集成`.NET Aspire`。
- `ApiStandard` 使用 `Swashbuckle` 提供 OpenAPI JSON，并在非生产环境提供 `/swagger` UI；`MiniApi` 使用 ASP.NET Core OpenAPI，默认文档为 `/openapi/v1.json`。
- 默认使用`.slnx`作为解决方案文件。
- 默认使用`CPM`中央包管理。
- `ApiStandard` 默认按多租户运行；初始化时会为 `default.com` 写入默认业务和分析数据库连接串，租户解析不会对缺失或未知租户静默回退。

### 版本兼容矩阵

| 组件 | 当前版本/要求 | 说明 |
| --- | --- | --- |
| `Perigon.templates` | `1.3.14` | 本页对应的模板包版本 |
| .NET SDK | `10.0.103` 或兼容的 .NET 10 SDK | 两套模板目标框架为 `net10.0` |
| Aspire AppHost SDK | `13.5.0` | 当前开发版本，两套模板统一版本 |
| Aspire Hosting 包 | `13.5.0` | 与 AppHost SDK 保持一致；EF Core 和 Kubernetes hosting 包当前为 preview 包 |
| `ApiStandard` | `perigon-webapi` | EF Core、Aspire 迁移资源、Admin/API、多数据库 |
| `MiniApi` | `perigon-miniapi` | Minimal API、PostgreSQL、NativeAOT、无内置 EF 迁移资源 |

模板包版本和文档版本不是同一个概念：`10.0`表示 .NET/Perigon CLI 主版本线，`1.3.14`表示 `Perigon.templates` 发布版本。升级模板包时，应同步更新本矩阵和两套快速入门。
