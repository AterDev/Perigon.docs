# Getting started

## Requirements

- Windows 10 version 1809 (build 17763) or later.
- An x64 Windows desktop device.
- A keyboard and mouse for capture interaction.
- OCR is optional and requires the relevant Windows OCR language pack.

## Take your first screenshot

1. Launch EasySnipping. The app runs in the system tray.
2. Press the default shortcut, `Ctrl+Shift+S`, or choose the capture command from the tray menu.
3. Move the pointer over the target window or control. Smart selection shows the current candidate region.
4. Click to confirm the automatic candidate, or drag to create a free-form selection.
5. Use the toolbar to annotate, recognize text, save, copy, or pin the confirmed selection.

Press `Esc` or the right mouse button to cancel. After a selection is confirmed, drag inside it to move the selection or use any of its eight handles to resize it.

## Change shortcuts and defaults

Open Settings from the tray menu. On the General page you can change:

- The global screenshot shortcut, which defaults to `Ctrl+Shift+S`.
- The always-on-top pin shortcut, which defaults to `Ctrl+T`.
- The save directory, default format, and JPEG quality.
- Whether EasySnipping starts with Windows.

Select Save when you are done. If another application already uses a shortcut, choose a different combination.
