# 快速开始

## 系统要求

- Windows 10 版本 1809（内部版本 17763）或更高版本。
- x64 Windows 桌面设备。
- 键盘和鼠标用于截图操作。
- OCR 为可选能力，需要系统安装对应的 Windows OCR 语言包。

## 第一次截图

1. 启动 EasySnipping。应用启动后会驻留在系统托盘中。
2. 按默认快捷键 `Ctrl+Shift+S`，或者右键托盘图标并选择立即截图。
3. 将鼠标移动到目标窗口或控件上。智能选区会显示当前候选区域。
4. 单击确认自动选区，或按住鼠标拖拽创建自由选区。
5. 在选区确认后使用工具栏标注、识别文字、保存、复制或置顶。

按 `Esc` 或鼠标右键可以取消当前截图。确认选区后，可以拖动选区内部移动它，也可以使用八个方向的手柄调整边界。

## 修改快捷键

打开托盘菜单中的设置，在“常规”页修改：

- 全局截图快捷键，默认是 `Ctrl+Shift+S`；
- 置顶贴图快捷键，默认是 `Ctrl+T`；
- 保存目录、默认保存格式和 JPEG 质量；
- 是否随 Windows 启动。

修改完成后选择“保存”。如果快捷键与其他软件冲突，请换用未被占用的组合键。
