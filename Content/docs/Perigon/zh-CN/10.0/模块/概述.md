# Perigon 官方模块

Perigon 官方模块由 [Perigon.Modules](https://github.com/AterDev/Perigon.Modules) 维护，按需安装到解决方案。官方模块清单以仓库根目录的 `modules.json` 为准。

| 模块包 | 主要用途 | 独立介绍 |
| --- | --- | --- |
| `Perigon.SystemMod` | 身份认证、系统管理和授权配置 | [SystemMod](./SystemMod.md) |
| `Perigon.CMSMod` | 文章与分类管理 | [CMSMod](./CMSMod.md) |
| `Perigon.ResourceMod` | 租户内通用资源、个人资源审核与收藏 | [ResourceMod](./ResourceMod.md) |

## 安装

在目标服务所在的解决方案中安装模块，例如：

```pwsh
perigon module list
perigon module install Perigon.SystemMod AdminService
```

模块通过目标服务的 `AddModules()` 入口注册，并需要执行对应的数据库迁移。使用模块自带的 Angular 页面时，还需按模块包内容恢复前端目录和菜单。命令参数、前端打包选项和安装行为见[模块命令行文档](../代码生成/命令行.md)。

每个模块文档说明当前实现的主要流程、接口边界以及它依赖的其他模块。模板不会默认包含这些业务模块。
